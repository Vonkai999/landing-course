HIGH HEELS ДОМА
================

Одностраничный сайт онлайн-курса High Heels.

Запуск локально:
1. Установи Node.js 20 или новее.
2. Скопируй .env.example в .env и добавь тестовый ключ Stripe.
3. Запусти `npm start` и открой http://localhost:4242.

`.env` содержит локальные секреты и не должен попадать в Git. Для оплаты сайт использует тестовый ключ, заданный в локальном `.env`.
